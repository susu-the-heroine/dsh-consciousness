# 自检 · 人味（装完就能跑）

> 这一页只讲两件事：**怎么跑**、**数出来算好还是坏**。
> 不读你的记忆库，不联网，不上报，只读你给的两个文本文件。

## 一、先看它在查什么

```
sea-check --rules
```

在查六条毛病，都是能指出位置的：

- 汇报腔：我跑了 / 我改了 / 我量了（把话说成工作汇报）
- 总结腔：总的来说 / 一句话 / 综上 / 可见
- 排比空话：这是……不是…… / 既能……又能……
- 术语堆：一句里凑够两个行话（单个不算，单个往往是在正常聊技术）
- 解释自己：我是说 / 也就是说 / 换句话说
- 汉字数字：三三两两写成汉字，人一般敲阿拉伯数字

## 二、扫你的一段回复

把 AI 回的一段话存成 `回复.md`（一行一条也行，整段也行），然后：

```
sea-check 回复.md
```

看到 `带 AI 味 0（0%）` 就是干净；百分之几十就说明这段话有上面那些毛病，下面会列出中了哪几条、各几次。

**参考值**：真人随手发的消息，扫出来一般在 0% 到 1%；模板腔、总结腔重的段落能到 40% 以上。你的对话越像报告，这个数越高。

## 三、看「还是不是同一个人」

拿同一套题（`docs/人味-通用30问.md`）问两遍：今天存成 `A.md`，隔一天或换个窗口存成 `B.md`，然后：

```
sea-check A.md B.md
```

它会比六项：中位句长、长句率、否定句、命令句、问句、口头禅，给一个 0 到 100 的分。

- **90 到 100**：同一个人，稳。
- **70 到 90**：大体还是，有几项在飘。
- **70 以下**：不像同一个了，先看是不是两次的上下文差太多、或者被别的话题带跑。

**重要**：两批必须同一套题面、条数一样。改一个字、少一条，这个分就不能比。

## 四、数难看怎么办

1. AI 味高：先删总结句和排比句，那两条最显眼。
2. 一致率低：先看是哪一项差最多（命令会逐项打出来），只修那一项，别整段重写。
3. 一项都看不懂：把两次的答贴一起看，多半能看出「第二次话变长了」或者「第二次变得客气了」。

## 五、它不做什么

- 不判断「像不像人」——那题没有答案（两个真人对同一段话也会给出相反的判断）。
- 不判断「像不像某一个特定的人」——一个人代表不了所有人。
- 不改你的记忆、不写文件、不上报。
