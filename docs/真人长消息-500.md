325. 一、输入法手滑错误（最高频，打字专属，说话没有）  1. 形近键位误触（键盘相邻） 比如想打“没事”打成“木事”；“等会”打成“等合”；“知道了”打成“知到了”；想打“好”按到旁边“和”；长句中间穿插一个错字，自己甚至没发现就发出去。 特点：错字和正确字读音不一定相近，只是键盘挨在一起。真人经常打完不回看直接发送。 2. 联想词绑架（输入法自动推荐，手快点错） 想打“吃饭”，联想出来“喝茶”直接选中；本来想表达“我有点难过”，联想跳成“我有点麻烦”；输入半截拼音，输入法补了一句完全不是自己想说的话。 典型例子：本来：“晚上要不要出来”，手快选联想，发成“晚上要不要吃药” 3. 删改残留（改句子没删干净，一句话混杂新旧内容） 原本：“明天我去找你” 想改成“后天我去找你”，删的时候漏字，最后发出：明天后天我去找你 或者：“我不太喜欢这个东西” → 修改成“我挺喜欢这个东西”，残留成“我不太挺喜欢这个东西” 这一类对记忆插件杀伤力很强，前后信息冲突，非常考验识海的冲突权重判断，刚好是你之前断言要覆盖的场景。  4. 拼音简写、打一半拼音混汉字 “等下我wq去拿东西”、“你k看一下”；只打首字母，且首字母有多重歧义： “cy”：吃药/抽烟/茶艺/春游，没有上下文根本分不清。  二、语音转文字带来的错误（很多人发语音转文字，也是线上聊天一大来源）  哪怕是人打字，很多人的表达习惯和语音转文字错误高度重合：  1. 同音不同字批量出错：“权利/权力”、“形式/形势”、“需要/须要”、“力度/力度”、“期间/其间”  2. 漏助词、乱加助词：“昨天去超市买苹果”转成“昨天去超市苹果”  3. 断句完全错乱，一句话切得稀碎，不该加句号的地方乱加句号 样例：我下午出门。买了奶茶。还有面包。给你带了。 4. 连读识别跑偏：“我没明白”识别成“我每明白”；“等一会”识别“等一会”  三、句子残缺、截断、中途放弃表达（非常真实）  分几种不一样的心理成因：  1. 写到一半，突然不想说了，直接停住，没有收尾： “我昨天遇到一个很离谱的人他……”  2. 写到一半，觉得没必要细说，主动砍掉后半段事实，只留情绪： 本来想说“昨天他放我鸽子，我很生气”，最后只发：“昨天真的气死我了” 👉 重点：只留存情绪，删除事实背景。长期记忆演化里，时间久了，记忆就只剩下情绪，忘掉起因，这个就是你仿生衰减非常需要模拟的样本。  3. 中途换想法，一句话内部直接跳转话题，没有任何过渡： “周末要不要一起出去玩，对了，你上次借我的充电器什么时候还给我” 人脑是想到啥说啥，句子逻辑是跳跃的，不是论文那种顺承结构。  四、指代混乱（识海最容易翻车的一类）  1. 就近指代混乱，一句话里面多个主体，“他/它/这个/那个”分不清 “我昨天和小周、小吴碰面了，他跟我说那件事搞定了” 到底是小周还是小吴？人自己心里知道，但是文字记录没有标记。 2. 跨会话远距离指代：隔了几十条消息之后，单独发一句：“那件事怎么样了？” 没有前置说明，新的上下文里完全不知道“那件事”指代什么。  3. 代词混用：分不清人、物品、动物，“它、他”随便打。  五、人主观记忆自带的失真（这个是你项目核心！不是打字失误，是人本身记忆的特性）  不是手滑打错，是人回忆的时候天然会篡改细节，所有人都会，不是撒谎：  1. 时间偏移（最普遍） 把发生在周一的事，回忆成上周；上个月的事，说成几天前；两件先后发生的事，颠倒先后顺序。  2. 细节置换（移植记忆） A事件里面的一个细节，被人挪到B事件上。 例子：上周奶茶店和朋友吵架；上周另一天丢了钥匙。很久之后回忆，会说成：在奶茶店丢了钥匙。  3. 细节压缩、模糊化 原本很长一段经过，回忆的时候自动精简，丢失很多限定条件。 原事实：“上周三晚上八点，在城东那家便利店买了橘子，有点酸” 一段时间后人复述：“我之前买过橘子，很酸”，地点、时间全部丢掉，只剩下核心感受。  4. 感受放大/淡化 当时只是有点不爽，隔很久回想，主观感受加重，说成“当时特别生气”；当时很激动的事，过几个月回想，情绪变淡，描述轻飘飘。  5. 脑补补全空白 记不清中间过程，人脑自动编造合理的中间情节把故事串起来，自己完全意识不到是脑补的。  六、语言自带的歧义、模糊表达（人不会把话说得精确严谨）  1. 模糊量词，没有准确边界： “一会、晚点、不久、大概、差不多、好几次、一点点” “我晚点找你”——晚点是十分钟？三小时？明天？没有标准。  2. 主观定性词，没有统一标准： “很贵、很近、很好吃、有点吵”，全部是个人主观感受，不是客观事实。  3. 双重否定混乱，自己绕晕自己： “我不是不想不去”（本意：我想去，但是话说反了） “不是没有可能不做”，连人自己说完都容易搞反意思。  4. 对比省略： “这个更好”，没说和什么对比。  七、情绪化带来的表达变形（情绪上来的时候，语言逻辑会让步）  1. 极端概括（以单次事件概括全部） 一次迟到：“你每次都迟到”；一次做错：“你从来都不上心”。属于情绪下的夸张，不是客观事实。识海要区分和，权重分开，这个是你私有池、情绪联动模块的重点。  2. 重复叠句，靠重复表达情绪： “别这样别这样别这样”，没有新增信息，纯情绪强化。  3. 反向说气话、反话（反讽） “可真厉害啊”，实际是在吐槽。文字没有语气、表情辅助，非常难分辨。  4. 夹杂语气碎片、无意义助词： “害、哎、emm、额、啧、算了”  八、省略规则、圈内黑话、个人专属简写（个性化噪声）  每个人都有自己独一套说话习惯：  1. 自己固定简写，别人看不懂：比如你自己习惯“识海变阻器”简写成“变阻”，长期聊天圈子里才懂；  2. 省略主语：默认双方知道在聊谁，直接发“去了吗？”“搞定了？”  3. 表情包替代一句话：只发一个🥺😤，文字信息为空，情绪信息优先。  九、矛盾表达（同一个人，前后说法冲突，分两种）  1. 无心矛盾：记忆模糊、表达粗心，不自知 前一句：我不吃辣。隔一会：我昨天吃了爆辣火锅。自己忘了之前说的话。  2. 动态变化矛盾：人的想法本身变了，不是说错了 一开始：我打算下周去。过两天：我不去了。 👉 这个一定要区分开：是单纯说错了，还是人的想法发生更新。这就是你做confirm抬权重、doubt压权重逻辑的核心场景。  十、额外：排版标点的问题  • 完全不加标点，一长串文字堆在一起：“昨天出门买了奶茶很好喝就是排队很久”  • 标点乱用：句号问号感叹号随便混用，陈述句结尾打？  • 分段乱，一句话拆成好几条消息碎片化发送，一句话拆3、4条往外发，是微信、QQ聊天常态。 给你配套的使用思路（贴合你的500并行小白鼠测试）    1. 错别字、形近字：辩/辨、在/再、的/地/得，打错偏旁，比如“忘记”代替“忘记”  2. 同音字打错：“必需要”（需要）、有得（有的）、在见（再见）  3. 漏字：一句话少半个词，“我明天去市”（我明天去市里）  4. 四、记忆相关的错误（对你识海特别关键！）  1. 记错时间：把上周发生的说成上个月  2. 记错细节：记错颜色、地点、对方原话，大概复述，和原版有出入  3. 混淆两件相似的事，把A事件的细节安到B事件上  4. 记忆润色：时间久了，自己悄悄修改记忆里的情节，不是故意撒谎，是自然重构  5. 只记得感受，忘了起因：记得“当时很生气”，忘了为啥生气  五、逻辑、语言习惯问题
