# 自己验一遍（十分钟）

装完别信我说什么，跑这几条。每条都给你"应该看到什么"，对不上就是有问题，直接找我。

全部只读或只碰沙箱，不会动你自己的库。


> **自检脚本只在源码包（tgz）里有。**
> npm 包里只带运行必需文件（`index.js`、`client.js`、`lib`、`assets`、说明），不含 `scripts/` 与 `test/`——
> 那是为了不让包变胖、也不把开发用的语料带出去。
> 所以：从 npm 装的人，验证以 DSH 界面能不能用为准；想跑 `scripts/health-all.mjs` 这类自检，
> 用 `识海发版` 里的 tgz（见 `docs/安装-离线包.md`）。

## 1. 一条命令总检查

```
node scripts/health-all.mjs
```

应该看到五行都以「过」开头，最后一句「全部通过，可以放心用。」
它替你查：库与预算、十三个识海能不能读、JSON 与 SQLite 镜像一不一致、回归三十条、自检四十组。

## 2. 空白机器第一次用

```
node scripts/fresh-home-test.mjs
```

应该看到十条「过」，最后一句「空白机器：能自己长出目录、建海、写读都对。」
它把 HOME 指到一个空目录，从零开始跑一遍——别人装完第一次打开就是这种状态。

## 3. 陌生人不认识的库，还灵不灵

```
node scripts/bench-synth.mjs
```

约十秒。应该看到：随机基线头名 1.7%、前三 5.0%；字面+向量头名 94%、前三 99%；纯向量头名 92%、前三 100%。
这不是"我们自己的库"，是六个虚构的人（咖啡店、汽修、高三、养狗、独立开发、医院陪护），每人六十条记忆、二十四道题。
**这组数不好看才该担心：它说明换了人还认得出。**

## 4. 库大到几千条还来不来得及

```
node scripts/scale-bench.mjs real3000 8
```

约四分钟（建向量占大头）。应该看到单轮中位十来毫秒、九成线二十毫秒以内。
它只读 `~/.dsh/consciousness-seas/real3000/data.json`，不写。

## 5. 你自己的库今天什么状态

```
node scripts/status.mjs
node scripts/dup-scan.mjs main
```

前一条给条数、进检索多少、注入被压掉几成、备份占多大。
后一条查"同一件事是不是记了两遍"，应该看到「疑似重复 0 对」或明确列出来。

## 6. 发布包里有没有不该发的东西

```
node scripts/release-audit.mjs
```

应该看到「当前版本干净」。
它拿 `tar` 把包解出清单，对一张黑名单：评测语料、私人笔记、备份残件、node_modules、真实识海数据。
**这张名单是血换的**：0.3.9 到 0.4.0 那几个包里有 `scripts/data`，是从本人记忆里抽的评测题；
0.4.8 起才挡住。旧包它只报警告，不判失败——那些可能已经发出去了，得人来处理。

## 6b. 装好的那份能不能整包发给朋友

```
node scripts/share-check.mjs
```

应该看到「干净，可以整包发人」。
扫的是 `~/.dsh/profiles/<配置>/node_modules/dsh-consciousness2`——你手动拷进去、最可能直接压缩发人的那一份。
2026-11-15 凌晨它查出过十七项：学习笔记加十二份评测语料。清完是三百八十个文件、零项。

## 6c. 包里该有的都有吗（别人装得上吗）

```
node scripts/pack-graph-test.mjs
```

应该看到「扫了 104 个文件 · 问题 0」「入口能引到的东西都在包里」。
它顺着入口的 import 走一遍本地模块，再对 `package.json` 的 `files` 白名单——
`files` 是白名单，漏了的东西在别人机器上就是不存在。

## 7. 向量补齐了吗

```
node scripts/status.mjs        # 看「向量：活 N · 有 N · 缺 0」
node scripts/embed-backfill.mjs main   # 有缺就补（只写 vectors.json）
```

没有向量的记忆只能被字面找到，按意思永远搜不到，而且不报错。

## 7b. 真实问法题库（评测语料的来源）

```
node scripts/build-query-bank.mjs main   # 从问法日志抽"他真正问过的短句"
node scripts/bank-review.mjs main 0 20   # 一条问法 + 当时排在前面的记忆标题
```

抽出来的是**没标过的题**：`scripts/data/query-bank.jsonl`。
标注得人来：把每条的 `top` 改成"应该中的编号"；闲聊类（继续／在吗／你咋又停了）标 `null`——
"不该命中"也是数据，它量的就是误召回。

标完另存 `scripts/data/labeled-batch.json`。**别照记忆里的编号重造**，编号错一个分数就假。

## 8. 想自己看它检索得准不准

```
node scripts/eval-fusion.mjs main
```

约十七秒。它会同时报：只用向量、字面+向量、去掉问句虚词、图游走、伪相关反馈、新近加权、低分轮次。
里面有好几条是**被否掉的想法**，留着是为了下次别再试一遍——负结果也是结果。
