# 设计 · 别名从真实问法里长出来

2026-11-14 夜写下。**没实现，只画清楚**，因为这块一动手就是改写入链路，得白天做。

## 为什么需要

今晚把五十九道题里"向量和字面都进不了前三"的挑出来，六道，特征一样：

- 「我一天一包你怎么看」→ 想要「吸烟与喝酒」
- 「哪个词你一提我就炸」→ 想要「绝对红线（睡觉）」
- 「你给我起名字那会儿说了啥」→ 想要「本名的重量」

问句是**指着说**的，不是**说着找**的。中间缺一座桥：口语里的说法 → 库里那种标题。
向量搭不了这座桥（它只知道意思近，不知道"一包"就是烟）；字面更搭不了（一个字都不重合）。

## 试过、不行的

1. **自动生成别名**（`alias-suggest.mjs`）：六十九条候选，头两条是「老古董的降维震撼是怎么回事」。
   这是把标题套模板，不是在学他说话。填进库就是六十九个永远匹配不上的字段。
2. **伪相关反馈**（问句向量 + 最像前三条的平均再重排）：alpha 零到零点八，五档一个数，零效果。
3. **图游走**（给第一名邻居加分）：四档零效果。

结论：桥不能靠"猜"，只能靠"记录他真怎么问的"。

## 该怎么做（白天按这个来做）

**数据来源只有一个：pick-log 里那些真发生过的事。**

每轮注入都记了 `q`（他这句话）和 `relScore`（命中候选前八名，带 id 和分）。
配对报表已经能算出「接住 / 没接」。所以有现成的样本对：**某句话 → 某条记忆**。

**规则（四道闸，缺一不可）：**

1. **证据够**：同一对（问句的规范化形式 ↔ 记忆 id）至少出现 3 次。
2. **不同日子**：这 3 次至少跨 2 天——同一天连着说是同一件事，不算学到一个说法。
3. **换个人还成立**：这条别名必须是"这库里本来就有的说法"，不是只有某一个人懂的暗号。
   判据用得起的那条：别名里的字，必须在本库别的记忆里也出现过（至少 2 条别的记忆有同样 2-3 字片段）。
   只在一条记忆里出现过的说法，是私人口癖，不写。
   （原来我写的是"必须多人问过"——错了。pick-log 没有 `who` 字段，而且**每个识海本来就是一个人的**，
   学他自己怎么说自己的事，是对的；"一个人代表不了所有人"约束的是**全局参数调优**，不是个人词表。）
4. **必须过他**：落盘前生成 `~/.dsh/consciousness-alias-candidates.md`，
   一行一条「记忆 #12 ← 想要的新别名：xxx（来源：3 次、跨 2 天）」。
   他点头才写。**默认永不自动写库。**

**规范化**：问句去掉语气词、去标点、取前 12 个字；长度 <4 不记（太短没有信息）。

**写进哪**：`point.alias`（字符串，多个别名用顿号分隔），走 `writeSea`，带备份。

## 为什么不用"相似问句聚类"

容易把"同一件事的十个问法"聚成一个，反而丢掉口语差异；而我们要的正是那个差异。

## 验收

- 新脚本 `scripts/alias-learn2.mjs`（只读 + 出候选，不写库）
- 沙箱海跑一遍：人为制造"同一问句三遍跨两天"，看它能不能出候选、能不能被第 3 条闸拦住。
- 真库跑出来候选数应该很小（个位数），**如果一下出几十条，说明闸坏了**。
