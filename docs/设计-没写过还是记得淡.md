# 设计 · 「没写过」和「记得但淡」怎么分开

> 起因：2026-11-15 凌晨实测，六件库里确实没有的事（蜥蜴、冰岛酒店、外婆家门牌号…），
> 四条会递一张不相干的卡片。我试着用分数阈值拒答，三版都伤到真问题——
> 陌生识海端到端从 0/12 错变成 1/12，撤了。
> 这份文档把“为什么阈值不行”和“该怎么做”写清楚，不再瞎试。

## 一、先分清三种状态，别混成一种

| 状态 | 用户听到的应该是 | 库里长什么样 |
|---|---|---|
| 写过、能用 | 给他内容，加一句“就这些” | 活着的条目，有向量、有索引 |
| 写过、沉了 | 「有过这块，X 天前沉下去了，要捞吗」 | `archived: true`，正文还在 |
| 从没写过 | 「没记过这一块」，不给卡片 | 哪都没有 |

现在第二种已经能说对（昨晚修的提示），第三种还是错的——它会拿张不相干的卡片凑数。

## 二、为什么纯分数阈值不行（实测）

我试过三个值：

- 阈值太松（0.42）：六件假事只拒掉两条，还会把「他家那条全国最长的城市主干道」这种真问题也拒了。
- 阈值抬到 0.50：假事拒掉四条，但真问题误杀更多，端到端从 0/12 变成 1/12。
- “分数 + 字面稀有词 + 只有一两条候选”组合：能到 4/6，但依旧误杀。

根因：**语义分数不区分“弱相关”和“无关”**。问“蜥蜴”和问“经十路”，都能在库里找到一条
语义 0.4 左右的邻居——一个是巧合，一个是真事。分数一样。

## 三、该用的证据（按硬度排）

1. **实体命中**：问句里出现的名词，库里有几条提到过。零命中 → 强烈倾向“没写过”。
   （现在实体表有 195 个词，够用；比字面词准。）
2. **标题/别名近似**：问句和某条标题的字面重合度（去掉虚词后）。这是“问的就是这条”的证据。
3. **FTS 命中**：全文索引里有没有这几个词。一条都没有，基本可以断定没写过。
4. **语义最近邻距离**：只当旁证，不当判据——上面三条都弱的时候，它救不了场。
5. **时间/人物指代**：问“那次”“他说的那句”时，时间窗和人名可以缩小范围。

判定顺序：先看 1/2/3 有没有硬证据；三条全零，才说“没记过”；
任何一条有，就正常给结果，哪怕语义分低。

## 四、今晚不做的事

- 不再拿单个阈值去切。
- 不加“模型自评这条像不像”的回路——它会把不相干的也评成“像”。
- 不为跑分调参。

## 五、验收（写死在回归里）

同一批题，跑两遍：

- 六件假事：拒答 **≥5/6**，且**不许**出现“递了一张卡片还说这是你要的”。
- 五件真事（含“那条一万三播放的作品叫什么”“他家那条全国最长的城市主干道”）：
  **零误杀**。
- 陌生识海端到端：**0/12 错**（现在是 0/12，改了也不许变）。
- 留出集前三不许掉：真工具口径现在 15/20（主库无关系）、16/20（沙箱有关系）。

四条同时成立才算做成；任何一条破了就回滚，不留半成品。

## 六、动手顺序

1. 先把“实体表 + 标题近似”写成只读打分器（`scripts/ghost-check.mjs`），
   拿上面十一题跑，看能不能把真事和假事分开——先看它能不能分清，再谈改检索。
2. 分得清，就把这个证据并进检索的“是否拒答”判断；分不清，就换证据，不动检索。

## 七、先量了一轮（2026-11-15 02:55，scripts/ghost-check.mjs）

十一题上，三种证据分得开：真事五件「稀有词命中」是 6、9、5、3、6；假事六件是 1、0、0、1、1、0。
中间有个空档（1 对 3），看着像能用一条线切开。

但拿九十条真问题去验，**二十四条会被切掉**：最少 0、中位 2——「他家几套房」「他前阵子住院什么病」
「你第一次叫我名字是什么感觉」这种，问句本来就短、词又常见，特殊词命中低是正常的，不等于没记过。
（那五件真事之所以命中高，是因为问句长、带了原话里的词。）

结论：**单靠“稀有词命中”做拒答，会冤枉四分之一真问题**。这条线不能画。

下一步要的是第三种证据：问句里的人和物，能不能在实体表里找到对应；以及问的是“有没有过”还是“要具体值”。
在那之前，宁可留着“凑出来的”那句提示，也不动检索——凑的至少标了，误杀是直接不认账。

## 八、目前最好的候选规则（还没上线，等你点头）

把两种证据叠起来：**问句里没有一个两字词出现在任何标题或别名里**，并且**稀有词命中 ≤1**
→ 判"没写过"。

- 假事六件：拒掉 **4/6**（原来 0/6；加豁免后不变）
- 加了一条豁免（头一条语义 >=0.5 就不拒）之后再量：真问题九十条误判 **2/90**（2.2%），
  剩下的是「他穿多大鞋」「他喜欢吃辣吗」——
  这三条库里其实有内容，只是问句里没带标题用词。
- 代价：三个人里有一个会被要求"换句话再问"。

比先前两版好一个量级（那两版误杀 24/90、且端到端破线）。3/90 这个代价我觉得可以接受，
但**没上线**——要不要用一句"没记过，换句话再问"换掉四次硬塞卡片，白天你定。

再往上要的是"问句意图"（问有没有 vs 问具体值）和实体表覆盖，那是另一轮工。
