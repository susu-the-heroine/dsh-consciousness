# 模块五 · 人怎么表达情绪（一）：语气不在字面里

> 本篇：*Beyond semantics: Prosody can shape and modulate listeners' emotional judgments*（2026）PLOS ONE，PMCID: PMC13552738。
> 分级：B+ / 一手（两个实验：声学测量 + 韵律-语义一致性操纵；读到摘要）。
> 为什么读它：识海只有字，没有声；得先知道「声」承担了多少，才知道文字该怎么补。

## 卡 1 · 情绪先从声音里出来，不听懂内容也能判断

- 我的复述：让听者听不懂语义时，仅凭韵律仍能判断快乐还是悲伤——说明情绪有一部分直接挂在声音上。
- 能推翻它的证据：若去掉语义后判断跌到随机水平，说明情绪全靠内容。
- 规则：识海的文字必须承担「声音」那部分功能；只写内容不写语气，等于把人声抽掉。
- 指标：同一内容两种写法（平铺 vs 带语气），用户判断情绪的一致率。

## 卡 2 · 快乐与悲伤的声学指纹是反的

- 我的复述：快乐朗读音高更高、更响、语速更快；悲伤更低、更轻、更慢，谐波性也更低。
- 能推翻它的证据：若换语言/文化后指纹翻转，这条只对特定语言成立。
- 规则：文字对应——高兴就短句、快节奏、多感叹；难过就长句、慢、少标点、留白。
- 指标：用户对「情绪对不对」的判定准确率（分四类情绪测）。

## 卡 3 · 语气与内容一致时加成，冲突时语气赢

- 我的复述：实验二操纵韵律与语义一致/冲突，看情绪判断怎么变——提示语气会调制甚至压过字面。
- 能推翻它的证据：若冲突时判断以字面为准，说明语气只是修饰。
- 规则：识海别在难过的话题上写轻快句子；字面和语气打架时，人会信语气。
- 指标：内容-语气冲突的回复，被读成「敷衍/阴阳」的比例。

## 卡 4 · 语速是可写的

- 我的复述：语速是声学指纹之一（快/慢），而文字里语速对应句长与断句密度。
- 能推翻它的证据：若读者对句长不敏感，这条要换成别的替代物（如标点密度）。
- 规则：情绪高时句子变短、句号变少；情绪低时句子变长、停顿变多。
- 指标：情绪标注与平均句长的相关性（应有方向性）。

## 卡 5 · 文字补不回来的那部分要承认

- 我的复述：韵律里有音高、强度、谐波性，文字没有对应物——这部分补不回来。
- 能推翻它的证据：若表情符号/语气词能完全替代，这条可放宽；目前没有证据。
- 规则：识海不假装有声音；用词与节奏做到七成，剩下的直说「这话要是我能说出口，语气会软一点」。
- 指标：用户对「像不像在说话」的评分（分文字版与语音版对比）。
