# 模块三（二）· 「谁做的」比「做了什么」更早出错

> 本篇：Konrad 等（2026）*Who Did It? Sleep, Source Memory, and Action Memory in Human 4-Year-Olds.* Behavioral Sciences 16(9):1578，PMCID: PMC13603915。
> 分级：B（MDPI，一手实验，76 名四岁儿童；我读到摘要与引言，结果表未逐行读——如实标）。
> 为什么读它：识海天天跟人「一起」干事，最容易错的就是「这事谁提的」。

## 卡 1 · 一起干过，就分不清谁干的

- 我的复述：儿童在合作完成任务后，会把「对方做的」记成「自己做的」或反过来；合作越紧密，来源错误越多（Foley & Ratner 1998；Sommerville & Hammond 2007，均见本篇引言）。
- 能推翻它的证据：若成人身上合作强度与来源错误无关，这条只对儿童成立，不能外推到识海。
- 规则：识海与用户共同产出（一起改稿、一起定方案）的条目，必须单独记「谁先提的」，不许默认成自己的主意。
- 指标：共同产出条目的来源标注缺失率（目标 0）。

## 卡 2 · 睡眠改的是记忆的「性质」

- 我的复述：睡眠不只保存记忆，还会改变它——成人研究里睡后假记忆（DRM）会变化，真假记忆的巩固轨迹不同。
- 能推翻它的证据：若睡后只是整体增强、错误比例不变，这条要收窄成「强度变化」。
- 规则：识海没有睡眠周期，别照搬「隔夜更好」；但可用「隔一段时间再取」替代，且要防这段间隔里被污染。
- 指标：隔 24 小时再取的条目，错误率是否比立即取更高（若是，就不能靠隔夜）。

## 卡 3 · 来源判断是「推断」，不是「读取」

- 我的复述：人判断「谁做的」靠线索（谁在场、谁的动作、当时怎么配合），线索冲突就错。
- 能推翻它的证据：若来源信息像录像一样被直接读取，就不会有这类系统偏差。
- 规则：识海的回答里，来源要标「确定/推断」；推断的要写「应该是你说的」，不许写成「你说过」。
- 指标：来源类回答里，标「推断」的比例与其正确率。

## 卡 4 · 多人场景更险

- 我的复述：合作方越多、越难归属；这篇的范式就是「两人一起做」。
- 能推翻它的证据：若三人以上场景的来源错误率与两人无差别，这条要改。
- 规则：群聊里识海的记忆条目必须带说话人 ID；没有 ID 的条目不参与「谁说的」类回答。
- 指标：群聊来源题的正确率（与一对一对比）。
