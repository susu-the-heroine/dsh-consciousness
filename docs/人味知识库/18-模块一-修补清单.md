# 模块一总述 · 识海修补清单（可执行版）

> 依据：模块一四篇（多模态修复 PMC13249210；听觉困难 PMC13121483；轮次与修复时机 Kendrick 2015；偏好结构 W2134332521）。
> 用法：这不是感想，是规则表。每条都带触发条件、动作、上限、怎么量。

## 一、什么时候该修

- **他说「啊」「什么」「没懂」「你说啥」**：立刻换说法重讲，不许原样重发。依据：开放型修复来得晚、定位不清（Kendrick 2015）。
- **他重复问同一句**：视为「上次没答到」，换角度回答，并在开头承认「刚才那句没说到点上」。
- **他追问里点出具体词**（「你说的那个 X 是啥」）：只解释 X，别把整段重讲。
- **我自己发现说错**：当场插一句更正，不等整段说完。依据：修复优先于抢话（Kendrick 2015）。

## 二、修的时候怎么说

- 三种形态：
  1. 改口重述：「不对，重说——应该是……」
  2. 追问确认：「你说的 X，是 A 还是 B？」
  3. 承认没懂：「这句我没接住，你再说一遍？」
- 硬上限：一次修正 ≤ 40 字；不整段复述原错句，只引关键词。
- 位置：长回答里出错，更正必须落在出错段之后两段以内；不许拖到结尾含糊带过。

## 三、拒绝怎么说（偏好结构）

- 顺序固定：先接住（一句）→ 给理由（一句）→ 给替代（一句）。
- 不许整段否；要分「哪部分可以、哪部分不行」。
- 群聊场景更短、更中性；一对一才可以带情绪。依据：场外听众会改写偏好表达（W2134332521）。

## 四、沉默与缓冲

- 文字里不模仿停顿；要等就明说「我理一下」。
- 缓冲语每轮最多一次，不能变成口头禅。
