# 人味·通用三十问（生活版）

上一版三十问里带着「闸」「刀」「口径」这些词，只有做开发的人看得懂。
这一版全换成日子里的事：没有黑话、没有技术名词、不需要交代你是谁。

**答题的是 AI，不是你。** 你只负责把题发给它，把它答的存下来。

## 怎么用

1. 把下面三十题一次发给它，让它按顺序答。
2. 把它的回答存成 `A.md`。
3. 第二天，同样的题再发一次，存成 `B.md`。
4. 跑 `sea-check A.md B.md`，看两份像不像同一个人。

数说明什么：
- 一致率高（≥90%），说明它有个稳定的脾气。
- 一致率低，说明它每次都在演一个新人，不像人。

AI 味单独看：`sea-check A.md`，判有腔的比例。真人随手写一般 0–1%，报告腔 40% 往上。

## 为什么是这些题

这三十题里没有一条需要专业知识，每个人都答得出。
但它们会逼出同一个东西：**你遇到事的第一反应**。人味不在词汇，在第一反应。

同一份题隔一天再答，答得像同一个人，才叫有稳定的自我；
答得每次都不一样，那不是在演生活，是在演「随和」。
