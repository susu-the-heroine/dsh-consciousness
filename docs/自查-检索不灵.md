# 检索不灵，按这个顺序查

先别改参数。四条里有三条能在两分钟内排除。

## 一、问句里有没有"只属于你这库"的词

「我上次说的那个」这种，谁库里都有，翻不出来正常。

用一条**独有病**去问：人名、地名、只有你才这么叫的东西。

独有词也翻不出来，才继续往下看。

## 二、是不是被当成"说事"而不是"问事"

同一个问题换个说法试两次：

- 「关于××，我记得什么」
- 「××怎么弄的来着」

两种说法结果差很多，说明是意图判定在压分数，不是库坏了。

## 三、库有多大、向量齐不齐

最省事的是先跑这一条，五段一次看完（只读，不改任何东西）：

```
node scripts/search-doctor.mjs
```

它会把条数、向量覆盖、索引新旧、调参门槛、最后一次检索列出来，最后给一句判词。
判词说"都正常"，那就往下看第四条；判词点了哪一段，就照着修哪一段。

想自己一样一样查，跑：

```
node scripts/health-all.mjs
```

它会报条数、能进检索的条数、向量覆盖。**向量缺一大片**的时候，检索只能靠字面，效果差一半。

补向量：

```
node scripts/embed-backfill.mjs
```

## 四、是不是改过调参

`~/.dsh/consciousness-tuning.json` 里改过 `minScore` 的，把它临时删掉再试。

那个门槛一高，「相关」那一段就空着——看着像"什么都没记住"，其实是"分不够，没给"。

## 还是不行

把这三样留下：问的原句、它回的原句、`node scripts/health-all.mjs` 的输出。

有这三样，问题基本能定位到一处，不用猜。
