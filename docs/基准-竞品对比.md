# 竞品对比（2026-11-15 凌晨查的）

不是评测，是横向看一遍别人怎么做，找咱们该抄什么、别抄什么。
资料都是公开文档，链接附在文末。

## 别人的路数

**MemGPT / Letta**：把记忆分层。
- 核心记忆（core memory blocks）常驻上下文，每块 2000–5000 字符，建议 5–15 块，agent 自己能改。
- 外部记忆（archival memory）走语义检索，工具调用才取。
- 会话历史可搜。
- 多 agent 共享块有三种写法：追加（insert，最安全）、替换（replace）、整块重写（rethink，最后写的赢）。
- 他们文档自己承认并发问题：两个 agent 同时读同一块再写，后写的会把先写的覆盖掉——所以推荐用追加。

**Mem0**：夹在应用和模型之间的一层，负责从对话里抽取、合并记忆（增/改/删），底下接向量库和图存储。
卖点是"不用改你的应用"、"跨会话记住偏好"。

## 咱们现在的位置

先说位置：咱们不是通用记忆层，是**一个人的长期记忆**，重在"认得这个人"，不在"给所有 agent 供数据"。

咱们做得比他们细的地方：
- **写得稳**。他们是"最后写的赢"，咱们有真锁：等 3 秒拿不到就照写并留审计；锁的主人死了会被识别、立刻接手（实测 7 毫秒）。他们文档里那个覆盖问题，咱们这一层挡住了。
- **不擦原话**。改错只有三条路：批注（另起一段）、压可信度、钉时间；正文一个字不许动。他们那边块是直接改值的。
- **会淡**。强度、沉降、太久没想起来会沉下去，删掉的留暗点。他们没有"忘"这个设计。
- **有止损**。写之前备份留 14 天；条数缩水过半直接拒写。
- **零依赖、纯本地**。不联网、不装 Python、不调外部向量服务（模型包可选，不装就降级直扫）。

咱们明显不如的地方：
- **没有图关系**。Mem0 有图存储，能答"这两个人怎么认识的"；咱们只有条目之间弱关联和共现。
- **没有自动抽取**。咱们靠显式写 + 写时查重便条；他们从对话里自己抽事实。
- **没有多 agent 共享块**。咱们一个海就是一份，多个 agent 同时用要靠锁排队，没有"共享块"这个概念。
- **没有重排**。第一名六成五（留出集 20 题、调参集 57 题都一样），他们那边没公开同类数字，不能直接比。

## 该抄什么

1. **分层**：他们已经验证了"常驻块 + 外部检索"这条分层是对的。咱们其实也在做（底子/规矩/钉子常驻，其余检索），但没明确写出来，后面调阈值容易乱。
2. **追加优先**：他们推荐并发时用 insert 不用 replace——咱们写库是整份重写，靠锁兜底。锁以外，可以再给"追加式写入"留一条快路。
3. **块上限**：他们建议 5–15 块、每块几千字符。咱们常驻那段也该有个硬上限，超了就压。

## 别抄什么

- **别抄"最后写的赢"**。他们文档自己写了会丢改动，咱们已经用锁绕开了，别回头。
- **别为了图关系上外部图库**。那会破坏零依赖和本地优先，收益对"一个人用"不明显。
- **别抄自动抽取就不留原文**。咱们的价值一半在"原话不许改"，自动摘要会把这个优势弄没。
