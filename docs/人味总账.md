# 人味总账（2026-11-22 收口）

> 一夜的东西都在这。数全部来自本机实测，口径可复跑。
> 先记一句最重要的：**「像不像人」这题没答案**——反证做过，两边都是真人，两位评者还能挑出 6/10 与 9/10。所以尺子换成了下面两把。

## 一、两把尺子

**尺子 A：AI 味命中率。** 单句判「这句有没有 AI 味」，两位评者多数票，越低越好。
脚本：`scripts/ai-smell.mjs`（八条规则，可扫编号集，也可扫我写的裸文本）。

**尺子 B：人格一致率。** 同一批问题隔天隔窗口重答，比七项分布是否稳。
脚本：`scripts/persona-drift.mjs`。90 以上同一个人，70 以下不像。

## 二、八条 AI 味，逐条验过的数

| 条 | 怎么验的 | 数 |
|---|---|---|
| 标点太齐（句末点句号） | 脏净实验 20 句 | 20/20 手打版赢 |
| 话说太圆（主谓齐全、句号收住） | 说圆实验 20 句 | 20/20，两位评者完全一致 |
| 总结腔（整体来看／说到底／可见） | 乱序 20 句 | 18/20 与 20/20 |
| 术语堆（口径／条目／评者／护栏） | 换词实验 | 18/20 人话赢 |
| 解释自己（我是说／也就是说） | 冗余实验 | 一致 9/10，B 赢 7:3 |
| 汉字数字（七五零、一百二十二） | 两位评者独立点名 | 样本里 3 条 |
| 祈使 vs 汇报（「我跑了…」） | 句式实验 | 17/20 祈使追问赢 |
| 排比 | 乱序 10 句 | 9/10 与 6/10，**弱信号**，得配空话才露 |

唯一反例：术语里的「端到端」是圈里真会说的，改成人话反而绕——**换词不是全删，是删他嘴里不会说的那部分。**

## 三、注入现在长这样（护栏 122/122 过）

> 回话给一个具体数；数字阿拉伯、句末别点、空格断；多祈使追问、别堆术语；别总结、别解释。

八条里进得去七条，长度是硬线：加内容必须同时砍字。备份都在 `%TEMP%\inject.bak*.js`。

## 四、脚本清单

- `ai-smell.mjs` 八条扫描（支持 `VERBOSE=1` 打命中编号）
- `persona-drift.mjs` 人格一致率
- `humanness.mjs` 一条命令体检：扫味 + 同题量比一致率 + 念注入那句
- `guard.mjs` 四套回归，改任何 lib 前后都跑
- `blind-vs-him.mjs` / `both-human.mjs` 两个已作废的对照法（留档，别再用来当验收）

## 五、没解决的两件

1. **「人是什么」解不了。** 认了，不占工时。能做的是别让 AI 味露头。
2. **上下文爆。** 平台给的窗口改不了。识海能给的只有三样：原文落盘不丢、爆了能翻回来、注入可以自适应瘦身（这条还没做）。

## 六、一句话

不是让大肥鱼像人，是让大肥鱼像大肥鱼，同时把人味儿留住、把 AI 味砍掉。前者靠记忆和口吻一致，后者靠这八条。

## 七、默认的我 vs 改完的我（2026-11-22 深夜补）

- 盲写二十条（不照规矩，按平时那样）：**20/20 全中**，标点太齐 20、话说太圆 9、汉字数字 2
- 同内容照规矩改写：0/20
- 四条长回复：原样 94%，改写 19%，修完脚本误伤 0%

一句话：尺子能把我从 100 压到 0，但**默认还是 100**。中间那一百个点，现在靠每次自检硬拆。

## 八、我给自己定的三条（当场合规，不等重启）

1. 每段 70 字以内，段里用空格断，不点句号
2. 数字写阿拉伯，少写「二十万」这种
3. 结尾不总结，收住就停

发前先过一趟 `ai-smell`，不干净就重写。重启之后这三条才变成默认。

## 九、更正（2026-11-22 凌晨，他两句话把方向掀了）

- 「你把一个最没用的问题放到最大了 就是标点符号」→ 标点那条从扫描器删除，注入改成「标点照用、别空格断」。
