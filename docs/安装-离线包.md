# 离线安装（不用 npm、不用联网）

给两种人看：一种是自己机器上没 npm，另一种是想把包直接发给别人。


> **自检脚本只在源码包（tgz）里有。**
> npm 包里只带运行必需文件（`index.js`、`client.js`、`lib`、`assets`、说明），不含 `scripts/` 与 `test/`——
> 那是为了不让包变胖、也不把开发用的语料带出去。
> 所以：从 npm 装的人，验证以 DSH 界面能不能用为准；想跑 `scripts/health-all.mjs` 这类自检，
> 用 `识海发版` 里的 tgz（见 `docs/安装-离线包.md`）。

## 包里有两个 tgz

```
dsh-consciousness2-<版本>-code.tgz    代码、页面、示例海、文档（约 17 MB）
dsh-consciousness2-<版本>-embed.tgz   量化模型与推理引擎（约 19 MB）
```

拆两个是为了「改一行代码不用重下二十兆模型」。装的时候两个都解，解到**同一个目录**。

## 装

一、找到你这个配置的插件目录。Windows 上长这样：

```
C:\Users\<你>\.dsh\profiles\<配置名>\node_modules\dsh-consciousness2\
```

配置名一般是 `desktop`。目录不存在就自己建。

二、把两个 tgz 里的东西解进去。tgz 里面有一层 `package/`，**把 `package/` 里面的内容搬进
`dsh-consciousness2\`**，别多套一层，别把 `package` 这层也搬进去。

PowerShell 里这么干（版本号换成你手里的）：

```powershell
$dst = "$env:USERPROFILE\.dsh\profiles\desktop\node_modules\dsh-consciousness2"
New-Item -ItemType Directory -Force -Path $dst | Out-Null
$tmp = "$env:TEMP\dsh-c2"
Remove-Item $tmp -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Force -Path $tmp | Out-Null
tar -xzf ".\dsh-consciousness2-0.4.8-code.tgz"  -C $tmp
tar -xzf ".\dsh-consciousness2-0.4.8-embed.tgz" -C $tmp
Copy-Item "$tmp\package\*" $dst -Recurse -Force
```

三、让你这个配置认它。打开 `C:\Users\<你>\.dsh\profiles\desktop\package.json`，
`dsh.profile.bundles` 里要有 `"dsh-consciousness2"`：

```json
{
  "dsh": {
    "profile": {
      "bundles": ["@deepseek-ai/dsh-base", "@deepseek-ai/dsh-web-app", "dsh-consciousness2"]
    }
  }
}
```

四、重启 DSH。侧边栏出现金圈「识」字就成了一半。

## 验

第一件事，验装对不对——**用这个，不要先用健康检查**：

```powershell
cd "$env:USERPROFILE\.dsh\profiles\desktop\node_modules\dsh-consciousness2"
node scripts\fresh-home-test.mjs
```

看到「空白机器：能自己长出目录、建海、写读都对」就成。
它自己造临时目录，不碰你的家目录。

想在装机上跑全面自检也行：`node scripts\selftest-all.mjs`。
新机器上它会显示「通过 15 · 失败 0 · 跳过 5」——跳过的那五组要先有你的库或沙箱海才能测，
它会把名字列出来，不算失败。等你记过几条记忆、再跑就是全跑。

`node scripts\health-all.mjs` 是**库里已经有记忆之后**才跑的全面体检——
首次装机它没东西可查，会直接告诉你「还没有识海，先跑上一个」，不算失败。

## 别人用的时候会问的三件事

**它会不会把我的记忆传到网上？**
不会。记忆全在你本机 `~/.dsh/consciousness-seas/`，这个包只读写本机文件。

**包里带不带作者的私人东西？**
不带。发布包有黑名单检查（评测语料、私人笔记、备份残件都挡在外面），
见 `docs/自己验一遍.md` 第 6 条。

**卸载会不会连记忆一起删？**
不会。删掉插件目录只删工具；`~/.dsh/consciousness-seas/` 和
`~/.dsh/consciousness-backups/` 是分开的两个地方，得你自己动手才会没。

## 装坏了怎么退

插件目录整个删掉，把 `package.json` 的 bundles 里那行名字去掉，重启。
记忆不受影响，重装回来它还在。
