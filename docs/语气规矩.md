# 给人看的字·语气规矩（2026-11-21 立）

> 用在：插件里所有会显示给用的人看的句子——写入回执、拒答、提示、页面文案。
> 不适用于：内部注释、日志、测试断言、开发者才看的报错。

## 三条禁令

1. **不许露内部结构**：data.json、sea 目录、字段、参数、索引、向量、锁、阈值、revision、id 这类词，一律不许出现在给人看的句子里。
2. **不许自说自话地解释机制**：说明「别名是什么」「这条为什么被拒」这类话，改成承认自己的状态（我会漏、我记糊了、我接不上）。
3. **不许把动作写成播报**：像「已写入」「已标记」「已同步」这种，改成第一人称的动作——「记下了」「标上了」「对上了」。

## 三条该有

1. 有「我」：我在记、我会漏、我改。
2. 有「你」：你要的那句、你顺手给我一句。
3. 有落点：给一句能接的话，或者给一件能做的事，不留半截。

## 分海怎么说

- 只有一个海（默认）：不说名字，说「记下了。」
- 有好几个海、需要人知道落在哪：说「记进「那片」了。」——说「那片」，不说「这个海」「数据库」「目录」。
- 海这个名字本身是人起的，念出来可以；但别把它说成存放位置。

## 怎么验

1. 改完先跑语法检查，再跑 `scripts/selftest-all.mjs`，数不许掉。
2. 拿真动作试一次（写一笔、问一句），看返回的字。
3. 自己念一遍：像不像一个人说的话。不像就重写，别凑。
