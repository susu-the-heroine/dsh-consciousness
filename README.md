# 识海

**作者：苏苏侠** · [gitee.com/susu-the-heroine](https://gitee.com/susu-the-heroine)

给 DSH 用的长期记忆。一条记忆一个神经元，会亮、会暗、太久没想起的会沉下去，删掉的变成暗点，闲下来它会自己回放一段往事。装完左侧栏多一个金圈「识」字，能写也能看。

**它不生产回复。** 它只负责在你说话的那一刻，把该提的那几条记忆递到模型眼前。**回复好不好是模型的活，料准不准是它的活。**

## 装

一条命令：

```
dsh plugin --profile desktop add dsh-consciousness2
```

装完**完全退出 DSH**（不是刷新页面）再开一次。左侧栏出现金圈「识」字就是好了。

**不需要 Python，也不需要联网。** 写记忆、存盘、检索、衰减、向量推理全在 Node 里跑，
量化模型（22.9 MB）和推理引擎（14.2 MB）随包发，装完就能按意思找。
只有"朗读"这一件要外部 TTS，没配就没有，其余照常。

**装之前先做一件事：确认 DSH 自己本来就能聊天。** 回不了消息的 DSH，装上插件也不会变好，只会让你以为是插件的错。原话和排错在 `INSTALL.md` 里。

## 更新

```
dsh plugin update dsh-consciousness2
```

不重装、配置不动、记忆不丢。

## 它不会自己记住

识海不会自己进上下文。**每开一个新窗口，先说一句「查一下识海」**，它才会去翻。

想让它自动记得：把 `记忆规则.md` 整段贴进你的 `AGENTS.md`。

---

## 能做什么

页面侧能操作：**搜索、点开、关联跳转、筛选、改、删（沉底）、导入、导出、快照、备份恢复、多识海、挂件。**

给模型用的 **18 个工具**，常用的这几组：

**记和查**：`memory_add`、`memory_list`、`memory_search`、`memory_trace`、`memory_count`
**让它会想**：`memory_think`（写进她自己的念头池）、`memory_ask`、`memory_analogy`（结构像不像）、`memory_story`（按时间串成一条线）
**关系那一层**：`memory_promise`（约定卡，谁答应了谁什么）、`memory_rhythm`（作息，照着预判什么时候出现）
**让它会淡**：`memory_sediment`（该沉淀成认识的）、`memory_archive`（淡到想不起来的收起来，能捞回）
**纠错**：`memory_confirm`（确认过的拉高可信度）、`memory_doubt`（怀疑的降下去，但不删）
**其它**：`memory_sea`（开新识海）、`memory_date`（把时间钉死）、`memory_judge`（给检索打分）、`memory_render`（重新导出页面）

## 它会忘，这是设计

太久没想起的记忆会按曲线淡下去，最后沉到底层——**能捞回来，不是丢了**。

**不会淡的**：规矩、禁区、承诺、你的画像，还有显式标成里程碑的那种。所以「不许提睡觉」这类，写一次就在。

想看某条为什么落在那一层，点开它，字段里有一个「理由」，写的就是命中了哪条判据。

---

## 它怎么称呼你

代码里不写死。配置在：

```
~/.dsh/consciousness-user.json
```

写成 `{"name": "你自己"}`，注入里就会用这个名字；**没这个文件，一律叫「他」**。

所以别人装上看到的是「他」，你这台是你的名字。**这是配置，不是代码**——改名不用改程序。

---

## 三档

`~/.dsh/consciousness-quality.json` 里 `{"quality": "low"|"high"|"max"}`，改完立刻生效，不用重启。

**low**：不注入，最省；只按字面找，不开向量和实体。
**high（默认）**：注入走核心，开向量和实体，按意思找。
**max**：在 high 之上加「顺着关联边再走一格」，能把中间那条挖出来；注入能到 7 条。

**max 更吃 token。** 不知道选哪个就留在 high。

---

## 语音（可选，默认不暴露）

插件**自己不发声**，只留一个接口 `/consciousness/speak`，把字交给你自己的 TTS。

配置写 `~/.dsh/consciousness-voice.json`（格式见 `lib/voice.js` 顶部）。没配就回「没配声音引擎」，不假装能响。

**页面上没有按钮**——因为它慢：一句话 2~30 秒，等生成完人早聊到下一句了。**别当对话用**，当「点一下听一句」可以。

---

## 把记忆拿走（纯文本）

跟它说一句「把记忆导成文本」，它就往 `~/.dsh/consciousness-mirror/<识海名>/` 导出一堆 `.md`，一条一个文件，记事本能直接开。
**导出的是只读副本**——在文件里改字不影响识海；要改记忆走页面里那条的编辑。

## 数据在哪

每个识海一个目录：

```
~/.dsh/consciousness-seas/<识海名>/data.json
```

备份在 `~/.dsh/consciousness-backups/<识海名>/`（留 14 天）。

**写入是原子的**：先写临时文件再改名，断电最坏是「还是旧那份」，不会留半截坏 JSON。

**写锁按识海一把**：网页和导入脚本同时写，会排队，不会互相盖掉。

**一个识海可以被多个窗口共认**：绑定关系存在 `~/.dsh/consciousness-bindings.json`，是「窗口 → 海」的方向，所以两个窗口同时用同一份记忆不会互相顶掉。

## 出问题先看这里

**症状：装上了、界面正常、球也在，但 AI 好像完全不知道有记忆。**

看这个文件，每几秒一行 JSON：

```
你的用户目录\.dsh\consciousness-audit.log
```

- 一直刷 `inject-tick-err`：注入没挂上，通常是有依赖没装好
- 一直刷 `inject-no-systemPrompt`：宿主没这个服务，插件在安静降级——**能聊，但记忆进不去**

**症状：改了配置没反应。**

插件在 DSH 启动时加载一次，**改完必须整个退出再开**。

**症状：记忆没写进去。**

看 `consciousness-backups\` 里有没有今天的备份。有备份说明写入通路是活的，只是那条没被判定成「该记的」。

**症状：换个说法就翻不出来。**

看 `http://127.0.0.1:<端口>/consciousness/vector`，`missing` 不是 0 就是向量层有问题。它挂了检索会明确告诉你「语义层这会儿没连上，只按字面找的」——**不悄悄降级**。
