# 识海

**作者：苏苏侠** · [gitee.com/susu-the-heroine](https://gitee.com/susu-the-heroine)

给任何 AI 用的长期记忆：DSH 里是插件，Claude Desktop / Cursor / Cline 走 MCP，其余聊天软件走 OpenAI 兼容反代，同一个内核、同一套数据。主要是给 DSH 用的，已过 L5 运行验证。零依赖，不用 Python、不联网，四万六千行，六十四项能力，自研模型 136.8 MB 塞在包里（双塔 98.9 MB + 旧引擎 20.5 MB + 内核 17.4 MB），一个字都不出你这台电脑。

记的比谁都细：事实、情绪、口头禅、句末点不点标点。查得算准：三路召回，再按句重排取前五，每条带原话和日期。T2Ranking 3371 条库、200 条真查询：top1 89.5%、top3 95.5%、top5 97.0%、top20 99.0%，前 20 漏 2 条。

已有真人在用，反馈一直在改它。

它还有脾气——会烦会闷，会认错，会照镜子。

## 两种装法

**给任何 AI（MCP / 反代）**

```
npm i -g shihai-mcp
shihai start
```

页面在 `http://127.0.0.1:7788`。MCP 客户端把 `shibai.mjs mcp` 挂上就是 23 个工具；聊天软件把 baseURL 指到 `http://127.0.0.1:7789/v1` 就是带记忆的对话。

**给 DSH（插件）**

```
dsh plugin --profile desktop add dsh-consciousness2
```

## 装

一条命令：

```
dsh plugin --profile desktop add dsh-consciousness2
```

装完**完全退出 DSH**（不是刷新页面）再开一次。左侧栏出现金圈「识」字就是好了。

第一次打开会看到八个示例海（葬礼、衰减、回放这些），是拿来给你看效果的；**主海是你在里面写下第一条记忆的时候才建的**，空着也不算坏。

不用装 Python，也不用联网。写记忆、存盘、检索、衰减、向量推理全在 Node 里跑，量化模型 22.9 MB 和推理引擎 14.2 MB 随包发，装完就能按意思找。只有「朗读」这一件要外部 TTS，没配就没有，其余照常。

**装之前先做一件事：确认 DSH 自己本来就能聊天。** 回不了消息的 DSH，装上插件也不会变好，只会让你以为是插件的错。

## 更新

```
dsh plugin update dsh-consciousness2
```

不重装、配置不动、记忆不丢。

更新完，或者你手动换了包里的代码，**一定要整个退出 DSH 再开**。浏览器刷新不算，插件是进程启动时加载的，不重开跑的还是旧代码。这条被踩过，改完怎么试都是老行为，白查半天。

## 它到底有什么

不依赖任何第三方库。不用装 Python，不用配推理环境，不联网。

自带一个 22.9 MB 的向量模型，语义比对全在本机算，一个字都不出你这台电脑。

四万六千行代码，一百四十二个功能，六十四项能力，二十三个记忆工具。

**写**
记一条、钉死真正发生的时间、认、疑、补注、查来龙去脉、列、搜、收别人的记忆、导出成纯文本。

**理**
七类记忆各有各的衰减排法——事实会淡、禁区不淡、承诺一直在。四档生命周期按被想起的次数往上升。能归档、能沉淀、能把两条拼出第三条、能找结构相同的旧事、能串成一条故事线、能按时间看出作息。

**约**
约定卡记谁答应了谁、兑现没有。能反问你。能自己数家底。能给检索打分。能另开一片海。

**查**
语义、字面、实体三路各出候选，重排之后只递前五条，每条带原话、日期、口气。有面板看命中率，有清单看哪句拖后腿。

**活**
写入原子完成、加锁、自动备份、能恢复、能整海搬走、能收别人的记忆、能导成纯文本。星图封顶 300 条神经，按被想起的权重挑着画，剩下的收在记忆库里，点开能翻、能改、能归档、能删。

**情绪**
八维情绪，记到几分熟、对谁。心境曲线。身体节律。一张心跳图。能一键抹平。

**她自己**
念头池里的话写下来不许改，只能删。自我描述只往上叠，不覆盖。口头禅。声音。

**性格**
学你的断句、口头禅、标点、句长。三次跨两天才收一条。你说别学我，那条当场钉死。默认关，超 200 毫秒自动断电。照镜子那把尺子校过，真人语料误报 1.0%。

**页面**
星图、记忆库、归档箱、故事线、工作台、内观、身体、数据、快照、导入导出、演示。

**不做**
不生产回复、不联网、不上传、不替你决定谁重要。

## 记忆多了以后

星图上最多站 300 条，挑的是权重最高的：重要度、情绪强度、被想起次数、是不是未了、是不是核心，加上「关系」「承诺」这类加分。测试和验证类会被降权。

名额按类别分配再按分数补齐，不会一屏全是同一种记忆。

剩下的全进记忆库——工具栏那个「记忆库」。按时间流动、能搜、点开看全文，正在图上的那 300 条标得更亮，一眼看得出哪些在台上。

分数并列时按被想起次数和编号固定排序，同一个库每次打开顺序一致，不会随刷新跳来跳去。

## 它怎么进上下文

每轮自动递几条。你说话的那一刻，它按你的问句去库里找，把最该提的那几条（默认两三条，最多七八条）追加到对话末尾。你不用点名。

但它递的是「最像的那几条」，不是全部。要翻旧账、要按时间看、要确认某件事到底写过没有，得明说一句「查一下识海」，那时走的是深搜那条路，不占每轮的额度。

想让它连人格、规矩也带着走，把 `记忆规则.md` 整段贴进你的 `AGENTS.md`。

## 它会忘，这是设计

太久没想起的记忆会按曲线淡下去，最后沉到底层。能捞回来，不是丢了。

不会淡的：规矩、禁区、承诺、你的画像，还有显式标成里程碑的那种。所以「不许提睡觉」这类，写一次就在。

想看某条为什么落在那一层，点开它，字段里有一个「理由」，写的就是命中了哪条判据。

沉到底的那批叫归档：不进检索、不上图，但一条不少。问到时它会说一句「这块我记着有过东西，X 天前沉下去了」，不会假装你从没记过。想看清单就说「看看归档箱」，想捞回哪条就说「把几号捞回来」。

## 记错了怎么办

三条路，都不改原来的正文。原来的话是你当时说的，改了就不是记忆了。

是同一件事、只是当时没写全，让它批一句。旧条下面多一行「现在的看法」，正文不动。

明显不对、可能是它自己编的，让它怀疑那条。可信度压下去，检索往后排，但记录还在，能捞回来。

时间记岔了，让它把时间钉死。钉过之后，作息、沉降、归档才准。

这三件事都在对话里直接说，页面上没有单独的按钮。判断标准就一条：事实变了就批注，事实错了就压可信度，时间错了就改时间，都不许把旧句子擦掉重写。

## 它怎么称呼你

代码里不写死。配置在：

```
~/.dsh/consciousness-user.json
```

写成 `{"name": "你自己"}`，注入里就会用这个名字；没这个文件，一律叫「他」。

所以别人装上看到的是「他」，你这台是你的名字。这是配置，不是代码，改名不用改程序。

## 三档

`~/.dsh/consciousness-quality.json` 里 `{"quality": "low"|"high"|"max"}`，改完立刻生效，不用重启。

low 不注入，最省，只按字面找。high 是默认，开向量和实体，按意思找。max 在 high 之上顺着关联边再走一格，能把中间那条挖出来，注入能到七条。

max 更吃 token。不知道选哪个就留在 high。

## 语音（可选）

插件自己不发声，只留一个接口，把字交给你自己的 TTS。配置写 `~/.dsh/consciousness-voice.json`，没配就回「没配声音引擎」，不假装能响。

页面上没有按钮，因为它慢：一句话 2 到 30 秒，等生成完人早聊到下一句了。别当对话用，当「点一下听一句」可以。

## 把记忆拿走

跟它说一句「把记忆导成文本」，它就往 `~/.dsh/consciousness-mirror/<识海名>/` 导出一堆 `.md`，一条一个文件，记事本能直接开。

导出的是只读副本，在文件里改字不影响识海；要改记忆走页面里那条的编辑。

## 数据在哪

每个识海一个目录：

```
~/.dsh/consciousness-seas/<识海名>/data.json
```

备份在 `~/.dsh/consciousness-backups/<识海名>/`，每次写前一份，最多留最近一百份，同一分钟里只留一份。

写入是原子的：先写临时文件再改名，断电最坏是「还是旧那份」，不会留半截坏 JSON。

写锁按识海一把：网页、导入、脚本三条路都会先抢锁，抢不到最多等 0.8 秒，还抢不到就照写并记一笔审计，不让人干等。

一个识海可以被多个窗口共认，绑定关系存在 `~/.dsh/consciousness-bindings.json`，是「窗口到海」的方向，所以两个窗口同时用同一份记忆不会互相顶掉。

## 出问题先看这里

装上了、界面正常、球也在，但 AI 好像完全不知道有记忆。看这个文件，每几秒一行：

```
你的用户目录\.dsh\consciousness-audit.log
```

一直刷 `inject-tick-err` 是注入没挂上，通常是有依赖没装好。一直刷 `inject-no-systemPrompt` 是宿主没这个服务，插件在安静降级，能聊但记忆进不去。

改了配置没反应，那是没重开 DSH。

记忆没写进去，看 `consciousness-backups\` 里有没有今天的备份。有备份说明写入通路是活的，只是那条没被判定成「该记的」。

换个说法就翻不出来，看 `http://127.0.0.1:<端口>/consciousness/vector`，`missing` 不是 0 就是向量层有问题。它挂了检索会明确告诉你「语义层这会儿没连上，只按字面找的」，不悄悄降级。

## 它做不好的三件

第一名只有六成五。留出集二十题里，十三个第一次就顶对，四个要看到前三才对，还有一个进前十。所以它默认递几条给你挑，不是只递一条。

跨海的关联没有。你把工作、家里分成两个海，它们互相看不见，想串起来只能同一条记忆两边各写一次。

图和文件不进记忆。它只认字，你发的那张图、那份 PDF，它记不住内容，只能记住「你发过」。

## 边界与限制

一、只保证中文。分词、同义词、语气判断、AI 味规则，全是照中文写的。英文、日文没测过。

二、只在 DeepSeek Harness 的桌面 Web 端验过，Windows 上。别的宿主、别的平台、别的版本，没验。

三、跨海不联。每个海是独立的一份，互不检索、互不合并。

四、图和文件不进记忆。能记的是文字；文件名会进去，图片内容、音频内容不会。

五、不保证「像某个人」。这是记忆系统，不是人格复制。它会记得你怎么说话，但不承诺变成谁。

六、风格与「她自己的底」默认关。开关是 `~/.dsh/consciousness-tuning.json` 里的 `styleOn`，默认 0；这两块只要一轮超过 200 毫秒就自动熔断，之后不再跑。

## 包里有什么、没有什么

有：代码、页面、八个示例海、量化模型与推理引擎、说明文档。

没有：你的记忆（一条都没有，记忆全在你本机）、开发者的私人语料、任何联网上报。它不往外发东西，也不读你聊天记录以外的内容。
